## 🚀 ЧТО ЭТО ЗА ИГРА?

**PSU SURVIVOR: TITANIUM HUNT** - это МЕГА-ЭПИЧНАЯ игра, где ты управляешь персонажем, который должен собирать хорошие блоки питания и избегать плохих! Каждый титановый блок питания приближает тебя к победе, а каждый плохой блок - к поражению! Выбери одного из трех уникальных персонажей, каждый со своей механикой игры!

## 🎮 КАК ИГРАТЬ?

### Управление:
- **←** - Движение влево
- **→** - Движение вправо
- **W** - Активация специальной способности персонажа
- **ПРОБЕЛ** - Перезапуск игры после поражения

### Типы блоков:
- **🟢 GOOD** - Обычный хороший блок питания (+10 очков)
- **🔴 KCAS** - Плохой блок питания (-20 здоровья)
- **🟡 TITANIUM** - Супер-блок питания (+25 очков, +15 здоровья)

## 👨‍👩‍👧 ПЕРСОНАЖИ И ИХ УНИКАЛЬНЫЕ МЕХАНИКИ

### 🤖 Товарищ С. (КЛАССИЧЕСКИЙ)
- Стандартная механика: собирай хорошие блоки для очков, избегай плохих
- Шкала здоровья: начинается со 100 единиц
- Особенность: сбалансированный персонаж для новичков

### 🔥 Вован-Алиэкспресс (ЯРОСТЬ)
- Уникальная механика: шкала ярости, которая наполняется при сборе блоков
- Активная способность (W): активирует режим ярости, увеличивая получаемые очки
- Особенность: рискованный геймплей с высокими наградами

### 💰 Кролик-Шнырь Облигац (ИНВЕСТИЦИИ)
- Уникальная механика: инвестиционный график и корзина блоков
- Шкала денег: тратится при сборе блоков, наполняя корзину
- Активная способность (W): продажа корзины по текущему курсу на графике
- Особенность: следи за графиком и продавай в нужный момент для максимальной прибыли

## 🔊 ЗВУКИ И ЭФФЕКТЫ
